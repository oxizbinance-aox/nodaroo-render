# Nodaroo Cinematic Render Service — dependencies (SLIM)
# Target runtime: Python 3.12 (the Nodaroo container runs Python 3.12.13).
# Keep this file TINY on purpose: on 23 Nov 2026 the Nodaroo container's
# pip failed with "No space left on device" (OSError 28) while downloading
# numpy / imageio — the 50 GiB server quota was fine (92 KiB used), the
# failure was in pip's temp/download area. So only flask + pillow live
# here; the service runs fully on those two (pure-Pillow 2D renderer).
# numpy and imageio[ffmpeg] are OPTIONAL enhancements: if the container
# has room, add them in the panel's PY_PACKAGES field (space separated):
#   numpy imageio[ffmpeg]
# With numpy installed the 2D renderer uses the faster numpy path;
# imageio[ffmpeg] supplies a bundled ffmpeg binary when the system has
# none. Neither is required for the API to start or for 2D rendering.
flask>=3.0,<4
pillow>=10.2
